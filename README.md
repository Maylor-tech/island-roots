# Island Roots 🌴

A modern web application for Island Roots, featuring a juice and pastry ordering system with admin dashboard.

## Features

- 🧃 Public menu with juices and pastries
- 📝 Order management system
- 🔐 Secure admin dashboard
- 🌙 Dark mode support
- 📱 Mobile-friendly design
- 💾 Local storage for orders
- 📊 Export orders to CSV
- 🖨️ Print-friendly order summaries

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/your-username/island-roots.git
cd island-roots
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Admin Access

To access the admin dashboard:
1. Navigate to `/admin`
2. Enter the password: `island2025`

## Tech Stack

- Next.js 14
- React
- Tailwind CSS
- Local Storage for data persistence

## Development

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm start` - Start production server
